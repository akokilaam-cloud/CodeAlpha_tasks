🤖 Rule-Based Chatbot Using Python
📌 Description

This project implements a simple extended rule-based chatbot using Python. The chatbot interacts with users through the command line and responds to predefined inputs such as greetings, questions, and exit commands using conditional statements.

🎯 Objective

To build a chatbot that demonstrates basic Python concepts like functions, loops, and if-elif-else statements through user interaction.

📋 Features

Handles multiple user inputs (greetings, questions, exit)

Case-insensitive input handling

Continuous conversation using a loop

Simple and beginner-friendly logic

🛠️ Technologies Used

Language: Python

Interface: Command Line / Terminal

🧠 Concepts Used

Functions

Conditional statements (if-elif-else)

Loops (while)

Input and Output

▶️ How to Run

Save the file as chatbot.py

Run using:

python chatbot.py


Start chatting!

📊 Sample Output
You: hello
Chatbot: Hello! Nice to meet you 😊
You: how are you
Chatbot: I'm doing well, thank you!
You: bye
Chatbot: Goodbye! 👋

✅ Conclusion

This project shows how a basic rule-based chatbot can be built using Python. It is ideal for beginners and academic mini-projects.
